# Life Expectancy Power BI Report

Open `LifeExpectancy.pbip` in Power BI Desktop. The PBIR report contains three pages of native Power BI visuals and uses a custom Health Outcomes theme.

The report links to the shared semantic model at `../4_PBIP/LifeExpectancy.SemanticModel`. Keep the repository folder structure intact so that link resolves. The `data` folder includes copies of the source and analysis CSV outputs for reference.
