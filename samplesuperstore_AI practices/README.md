# SampleSuperStore AI Practices

Analytics work sample built from `Orders.csv`.

## Contents

- `Orders_EDA.ipynb` - focused descriptive EDA, cleaning, trends, segmentation, and bottlenecks.
- `Orders_MLPractices.ipynb` - diagnostic, predictive, and prescriptive ML baselines.
- `Orders_Visualizations.ipynb` - reproducible visualization analysis.
- `SSS_hugging face.pbip` - Power BI Project entry point.
- `SSS_hugging face.Report/` - PBIR report definition with Orders Analytics visuals.
- `SSS_hugging face.SemanticModel/` - semantic model definition.
- `Orders.csv` - source dataset.

Open the `.pbip` file in Power BI Desktop to view or continue editing the report.
